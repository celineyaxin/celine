# 📚 学位论文格式验证工具

基于对外经济贸易大学中国金融学院金融类专业学位论文写作规范，自动验证Word文档(.docx)格式是否符合要求。

## ✨ 功能特点

- 🔍 **31项格式验证**：覆盖论文各部分的格式要求
- 📊 **详细报告**：生成HTML格式的验证报告
- 🎯 **精准定位**：明确指出错误位置和修改建议
- ⚡ **批量验证**：一次运行检查所有格式项目

## 🚀 快速开始

### 方式一：直接使用（推荐，无需安装 Python）

**Windows 用户：**
1. 下载 `dist/论文格式验证工具.exe`
2. 双击运行，浏览器会自动打开
3. 上传论文文档，查看验证结果

**Mac 用户：**
1. 需要先安装 Python（从 https://www.python.org/downloads/ 下载）
2. 双击 `start.command` 文件启动
3. 首次可能需要：右键点击 → 打开 → 确认打开
4. 浏览器会自动打开验证界面

> 💡 如果有 Mac 用户，可以在 Mac 上运行 `python build_exe.py` 生成 Mac 原生应用

### 方式二：使用 Web UI（需要 Python）

```bash
# 安装依赖
pip install -r requirements.txt

# 启动 Web UI
python app.py

# 浏览器访问 http://127.0.0.1:5000
```

### 方式三：命令行模式

```bash
# 安装依赖
pip install -r requirements.txt

# 验证单个文档（运行所有验证器）
cd validators
python run_all.py your_thesis.docx

# 静默模式（只显示汇总）
python run_all.py your_thesis.docx --quiet

# 生成HTML报告
python run_all.py your_thesis.docx --report

# 指定论文类型（博士/硕士）
python run_all.py your_thesis.docx --type 硕士
```

### 运行单个验证器

```bash
# 只验证目录格式
python v07_toc.py your_thesis.docx

# 只验证三线表
python v15_three_line_table.py your_thesis.docx
```

### 重新打包 EXE（开发者）

```bash
python build_exe.py
```

## 📊 验证结果说明

验证结果分为三个级别：

| 级别 | 符号 | 说明 |
|------|------|------|
| ❌ 错误 | `✗` | 必须修复，不符合规范要求 |
| ⚠️ 警告 | `!` | 建议修改，可能存在问题 |
| ✅ 信息 | `✓` | 验证通过或提示信息 |

## 🔧 技术实现

- 使用 `python-docx` 读取Word文档结构
- 直接解析 DOCX 的 XML 文件以获取更精确的格式信息
- 支持检测Word自动生成的目录、页眉页脚等动态内容
- 采用模块化设计，每个验证器独立运行

## ⚠️ 注意事项

1. **文件格式**：仅支持 `.docx` 格式，不支持 `.doc` 格式
2. **编码问题**：Windows系统请确保终端支持UTF-8编码
3. **Word版本**：建议使用 Microsoft Word 2016 或更高版本
4. **验证局限**：
   - 无法验证打印效果
   - 部分格式（如字体是否为黑体）需要人工确认
   - 图片内容无法自动检测
