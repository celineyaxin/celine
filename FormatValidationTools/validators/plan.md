# 论文格式验证模块计划

> 基于《中国金融学院金融类专业学位论文写作规范》（2025年5月版）

## 设计原则

1. **单一职责**：每个验证文件只验证一个功能
2. **独立运行**：每个验证器可单独使用
3. **统一接口**：所有验证器继承统一基类
4. **详细报告**：输出错误、警告、通过三种状态

## 验证器基类设计

```python
class BaseValidator:
    """验证器基类"""
    
    # 验证器信息
    name: str           # 验证器名称
    description: str    # 描述
    standard_ref: str   # 规范引用（如"规范6.1"）
    
    # 验证结果
    errors: list        # 错误列表（必须修复）
    warnings: list      # 警告列表（建议修复）
    info: list          # 信息列表（通过项）
    
    # 方法
    def validate(self, doc) -> bool
    def get_report(self) -> dict
    def print_report(self) -> None
```

## 使用方式

### 1. 单独运行某个验证器

```bash
python validators/v01_page_setup.py thesis.docx
```

### 2. 批量运行所有验证

```bash
python validators/run_all.py thesis.docx --type 博士
```

### 3. 生成验证报告

```bash
python validators/report_generator.py thesis.docx --output report.html
```
